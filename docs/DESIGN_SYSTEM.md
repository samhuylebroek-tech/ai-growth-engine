# Design system — 2026-11-14
## Complete product remake — 2026-11-15
The current product replaces the historical shell below with six primary destinations: Home, Growth Officer, Growth intelligence, Work & approvals, Knowledge and Settings. One navigation manifest supplies primary links, contextual tabs and search. Existing URLs remain supported.
Home is an unframed command center with a scoped question composer, review priorities, verified intelligence, objectives and honest missing-data states. Activity and performance sections can be hidden through local display preferences. The AI workspace brings conversations, confirmed context, related work, copy and Markdown export together. Knowledge now uses mobile-friendly records; Settings separates Workspaces, Team, Organization and Sign-in. Growth areas explain available planning versus unimplemented execution, rather than exposing many empty modules.
Manrope, neutral near-white/charcoal surfaces and restrained emerald actions remain, with blue and amber reserved for secondary semantic roles. Borders, 8px framed tools, consistent headings and reduced-motion-safe transitions define the system. The public entrance uses a generated editorial studio image; authenticated work remains focused on real data.
Fresh verification: desktop 1280×1800, tablet 823×698 and phone 390×844. Thirteen customer phone screens showed no document-wide overflow. Settled desktop/tablet Home, real AI result, phone result, dark phone Home, mobile menu and public entrance were visually inspected. No WCAG certification is claimed. Earlier notes below describe previous iterations, not the current navigation.

Implemented: Manrope typography; neutral light and charcoal dark surfaces; restrained emerald actions; global semantic OKLCH tokens; 8px cards; shared headings, status pills, controls and navigation. Theme selection is persisted locally (no tenant data).
Desktop 1280×1800 and phone 390×844 were inspected. Overview overflow was reproduced and fixed. Knowledge, activity and capabilities tables scroll within their containers. Navigation is sticky on desktop and a touch-friendly drawer on phones. Reduced motion and keyboard focus are supported.
Not a full WCAG audit. Remaining work: more comprehensive loading/error states, mobile card alternatives to wide tables, wider tablet/accessibility matrix and public homepage visual redesign.

## 2026-11-15 refinement
Shared page headings use a restrained 24px scale without a decorative divider. The overview uses unframed sections, sourced measures and a next-action list rather than metric cards. Navigation groups collapse; one code manifest feeds both the sidebar and searchable page dialog. Tablet layouts use the mobile drawer below 1024px, retaining room for actual content. Search has an accessible dialog name; overlays and dark selected states use semantic tokens. Desktop 1280×1800, tablet 823×698 and phone 390×844 were exercised; eight customer pages had no document-wide horizontal overflow. Dark overview and settled phone drawer were visually inspected. This is not a WCAG certification.
